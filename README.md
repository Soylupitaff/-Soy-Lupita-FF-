# SOY LUPITA FF — página web

## Cómo verla
Abre `index.html` en un navegador.

## Cómo publicarla gratis con GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets`.
3. En **Settings → Pages**, selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. GitHub te dará una dirección `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

## Personalización
- Cambia los enlaces de YouTube y Facebook en `index.html`.
- Sustituye los textos de agenda por tus horarios reales.
- Puedes agregar más imágenes dentro de `assets` y crear nuevas tarjetas en la galería.
